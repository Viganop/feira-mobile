## 🎤 O que falar (2 a 3 min)

**1. Gancho**
> "Quantos apps você já abriu hoje? WhatsApp, Instagram, banco, iFood? Quem cria tudo isso é o **Desenvolvedor Mobile**!"

**2. Aba Apresentação** (passe pelos ícones falando com suas palavras)

| Ícone | O que dizer |
|---|---|
| 💡 O que é | Cria os apps do celular e publica na **Play Store** e **App Store**. Usa câmera, GPS, digital, notificações. |
| 🧑‍💻 Dia a dia | Trabalha em equipe: o **designer** desenha a tela, o **back-end** cuida dos dados, e o **mobile** faz a tela funcionar. |
| 🏢 Onde atua | Bancos, delivery, Uber, saúde, agro, startups. Dá pra trabalhar **remoto**, até pra fora do país. |
| 🛠️ Ferramentas | Android = **Kotlin**, iPhone = **Swift**. O **React Native** faz os dois com um código só (é o da demo!). |
| 🎓 Como chegar lá | Curso de **ADS**: lógica, web, banco de dados. Quem sabe web já tem meio caminho andado. |
| 💰 Remuneração | Júnior ~**R$ 6.850** · Pleno ~**R$ 11.750** · Sênior ~**R$ 16.950** (Robert Half 2026). |
| ⭐ O que ajuda | Curiosidade e paciência. **Não precisa ser bom em matemática**, é mais lógica, tipo montar LEGO. |

## 💻 Se perguntarem do código

- **`import`** → a caixa de ferramentas; só pega as peças que vai usar.
- **`<Text>`, `<Image>`, `<TouchableOpacity>`** → texto, imagem, botão.
- **`useState`** → a memória do app.
- **`StyleSheet`** → a aparência (cor, tamanho, cantos).
- **WhatsApp** abre outro app; o **Mapa** mostra São Carlos.

---

## ❓ Respostas rápidas

- **Computador caro?** Não, um comum serve. Dá pra testar no próprio celular com o **Expo**.
- **Sem Mac faz app de iPhone?** Sim, com React Native. O Mac só é preciso pra publicar na App Store.
- **Site x app?** O site roda no navegador; o app é instalado, é mais rápido e usa câmera e GPS.
- **IA vai substituir?** Não, a IA **ajuda** o programador, mas quem entende o problema é a pessoa.
- **Isso é um programa?** É **um arquivo HTML só** que simula um celular e gera código React Native de verdade.
